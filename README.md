# DubTV+ 1.0.0

<img src="assets/icon.svg" width="80" alt="Логотип DubTV+">

Автор: **laynholt**. Неофициальный userscript, не связан с командой DubTV.

Userscript для Violentmonkey на `https://dubtv.pro`.

## Установка

1. Установите Violentmonkey в браузер.
2. Откройте **[последний релиз скрипта](https://github.com/Laynholt/dubtv-plus/releases/latest/download/dubtv-plus.user.js)** и подтвердите установку.
3. Обновите страницу DubTV.

Альтернатива: создайте скрипт в Violentmonkey и вставьте содержимое `dubtv-plus.user.js`.

Обновления проверяет Violentmonkey: `@updateURL` ведёт на `dubtv-plus.meta.js`, `@downloadURL` — на полный userscript в последнем GitHub Release. Исходники в ветке не используются как канал обновления. Автоматическая проверка должна быть включена в настройках Violentmonkey.

**Переход с неопубликованной версии 1.1.0:** этот первый публичный релиз имеет номер 1.0.0. Один раз замените код существующего скрипта вручную: автоматическое обновление на меньший номер не сработает. Имя и namespace сохранены; ваши настройки и скрытые тайтлы остаются.

Если DubTV+ уже установлен, замените код существующего скрипта, чтобы две версии не работали одновременно. Настройки открываются кнопкой **DubTV+** справа внизу. Кнопку можно перетащить мышью или пальцем; положение сохраняется. С клавиатуры: сфокусируйте кнопку через Tab, затем используйте Alt + стрелки. Во вкладке «Интерфейс» можно вернуть кнопку на исходное место.

Меню разделено на вкладки **Плеер / Интерфейс / Каталог / О скрипте**. Между вкладками можно перемещаться стрелками, Home и End.

## Что делает

- Восстанавливает **фактическую скорость видео** после смены серии, загрузки источника и позднего сброса. Использует штатную настройку скорости сайта — выбирайте скорость в обычном меню плеера.
- Запоминает **качество**, выбранное в обычном меню, включая «Авто». При смене серии повторно выбирает его через меню сайта. Если разрешение отсутствует, выбирает ближайшее ниже; если ниже нет — минимальное доступное. Исходное предпочтение сохраняется.
- Добавляет **⏮ / ⏭** рядом с кнопкой воспроизведения, в том числе в полноэкранной панели. Кнопки вызывают штатные «Пред.» / «След.» и отключаются на границах списка.
- Поддерживает переходы между страницами без полной перезагрузки и замену элемента видео.
- Меняет штатный **режим кинотеатра**: плеер занимает всю ширину и высоту окна, а страницу можно прокручивать к сериям и описанию. Внешний градиент скрывается. Пропорции видео сохраняются: при несовпадении формата экрана и кадра возможны чёрные полосы. Выход — та же кнопка, `T` или `Esc`.
- Показывает **реальное оставшееся время** с учётом фактической скорости. Например, 20 минут видео при 2× — примерно 10 минут просмотра.
- После ручной перемотки предлагает **«Вернуть назад»** на 8 секунд. Работает с полосой прогресса, стрелками и переходом к заданному времени. При смене источника/серии точка отмены очищается.
- Позволяет сворачивать **описание, комментарии и похожие тайтлы**, отключать размытый фон и выбирать максимальную высоту обычного плеера: 60, 75, 85 или 100% окна. Секции можно развернуть кнопкой рядом с заголовком.
- Добавляет **«Не интересно»** при наведении на карточку. Скрывает выбранный тайтл на главной, в каталоге, онгоингах и похожих. В настройках есть выбор тайтла без наведения и список скрытого с кнопками **«Вернуть»**. Это локальный фильтр данного браузера.
- Показывает в каталоге **статус из ваших списков**: «Смотрю», «В планах», «Просмотрено», «Отложено», «Брошено». Просмотренное можно скрыть отдельным переключателем. При недоступности списков фильтрация по статусу отключается, а в настройках появляется сообщение с возможностью повторить загрузку.

После установки один раз выберите нужное качество: сайт не хранит прежний выбор, поэтому скрипт не может узнать его задним числом. Скорость подхватывается из существующей настройки сайта.

При восстановлении качества меню может кратко открыться и закрыться. Если вы сами открыли настройки, скрипт дождётся их закрытия. На первой загрузке выбор качества применяется, когда сайт покажет элементы управления плеером.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `T` / `Esc` | Включить или выключить кинотеатр / выйти из него |
| `Shift+←` / `Shift+→` | Предыдущая / следующая серия |
| `X` / `C` | Скорость −0,25× / +0,25×, в пределах 0,25–2× |
| `G` | Перейти к времени: `3 15` / `03:15`, `1 02 30` / `1:02:30`; одно число — секунды вперёд |
| `Z` | Отменить последнюю ручную перемотку, пока доступна кнопка |

Клавиши определяются по физическому расположению и работают с русской раскладкой. Они не перехватываются в полях ввода, открытых диалогах, при композиционном вводе и с Ctrl/Alt/Meta. Штатные Space, F, M и стрелки остаются у сайта. Дополнительные клавиши можно отключить в настройках; выход из кинотеатра по Esc остаётся доступным.

Например, на позиции 4:00 ввод `30` переносит на 4:30. Для абсолютного перехода к 30-й секунде введите `0 30`. Время за пределами серии, отрицательные числа и неверные минуты/секунды отклоняются.

## Данные и ограничения

Плеер изменяется на страницах `/release/`. Скрипт использует cookie `player_speed` и записи localStorage `dubtv-plus-quality`, `dubtv-plus-options`, `dubtv-plus-hidden`, `dubtv-plus-hide-completed`. При запрете localStorage настройки действуют только в текущей вкладке до перезагрузки.

Для статусов выполняется запрос **GET `/profile`** к самому DubTV с текущей сессией: при входе в каталог и по кнопке «Обновить статусы». Списки читаются из JSON в HTML профиля, полученный код не исполняется. Статусы хранятся только в памяти вкладки. Скрипт не меняет ваши списки, оценки или аккаунт и не отправляет данные сторонним сервисам. Внешних библиотек и дополнительных разрешений Violentmonkey нет. После изменения списка или аккаунта без перехода на другую страницу нажмите «Обновить статусы» либо обновите страницу.

Режим совместного просмотра `/watch/` не изменяется. Запуск следующей серии и история просмотра остаются под управлением сайта. После обновления разметки, названий кнопок или формата профиля DubTV скрипт может потребовать обновления.

Автоматический пропуск опенинга/эндинга без таймингов не добавлен: у всех 12 серий проверенного тайтла эти поля пустые. Штатный пропуск сайта остаётся доступным там, где у него есть тайминги.

## Сборка и проверка

Для установки нужен только корневой `dubtv-plus.user.js`. Исходники: `src/player.js` и `src/library.js`. После их редактирования пересоберите файл:

```powershell
node build.mjs
node --check dubtv-plus.user.js
node build.mjs --check
node --test tests/metadata.mjs
python -m http.server 8765 --bind 127.0.0.1
```

Откройте последовательно, дожидаясь результата в заголовке вкладки:

- `http://127.0.0.1:8765/tests/player.html` — скорость, качество, навигация и замена видео.
- `http://127.0.0.1:8765/tests/qol.html` — кинотеатр, прокрутка, клавиши, оставшееся время и отмена перемотки; один тест удерживает перемотку 9 секунд.
- `http://127.0.0.1:8765/tests/library.html` — локальное скрытие, восстановление, статусы и ошибки загрузки.

Не запускайте тесты одновременно: они используют общие cookie/localStorage на localhost. Фикстуры очищают свои тестовые настройки на localhost и используют настоящий HTMLVideoElement с моделью штатного меню и ответов профиля. Для ручной проверки интерфейса есть `tests/qol.html?demo=1`.

На живом DubTV 10 октября 2026 воспроизведены оба исходных сброса: фактической скорости 2× → 1× и выбранного качества 720p → Авто после смены серии. Проверены разметка плеера, секций и формат данных профиля. Непустые списки проверены на фикстуре. Локальные проверки не заменяют проверку установленного скрипта на живом сайте.

## Выпуск обновлений

1. Измените `@version` и номер во вкладке «О скрипте» в `src/player.js`, обновите README.
2. Выполните сборку и проверки выше, закоммитьте исходники и оба сгенерированных файла.
3. Создайте GitHub Release с тегом `v<версия>`, например `v1.0.0`, на нужном коммите.
4. Workflow `Release userscript` проверит сборку и совпадение тега с версией, затем прикрепит `dubtv-plus.user.js`, `dubtv-plus.meta.js` и `icon.svg`. Дождитесь успешного завершения; до этого ссылки установки нового релиза недоступны.

Для обычного канала обновлений публикуйте стабильный релиз и отмечайте его как Latest. Предрелизы предназначены для ручной установки.
