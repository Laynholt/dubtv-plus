# DubTV+

<img src="assets/icon.svg" width="80" alt="Логотип DubTV+">

Удобный плеер и каталог [DubTV](https://dubtv.pro).

## Установка

[![Установить DubTV+](assets/install.svg)](https://github.com/Laynholt/dubtv-plus/releases/latest/download/dubtv-plus.user.js)

### ПК — Violentmonkey

1. Установите [Violentmonkey](https://violentmonkey.github.io/get-it/).
2. Нажмите **«Установить DubTV+»** и подтвердите установку.
3. Обновите страницу DubTV.

### iOS / iPadOS — Userscripts для Safari

1. Установите [Userscripts из App Store](https://apps.apple.com/app/userscripts/id1463298887).
2. Откройте приложение и проверьте папку скриптов. Включите расширение Userscripts в Safari и разрешите ему доступ к DubTV.
3. [Скачайте скрипт](https://github.com/Laynholt/dubtv-plus/releases/latest/download/dubtv-plus.user.js) и через приложение «Файлы» сохраните `dubtv-plus.user.js` в папку, выбранную в Userscripts.
4. Откройте DubTV в Safari и обновите страницу.

[Официальная инструкция Userscripts](https://github.com/quoid/userscripts#ios-ipados).

### Android — Firefox и Violentmonkey

1. Установите [Firefox для Android](https://www.mozilla.org/firefox/browsers/mobile/android/).
2. В Firefox установите [Violentmonkey](https://addons.mozilla.org/firefox/addon/violentmonkey/) — расширение поддерживает Android.
3. В этом же браузере нажмите **«Установить DubTV+»**, подтвердите установку и обновите страницу DubTV.

На реальном Android-устройстве скрипт пока не проверялся.

## Возможности

Настройки открывает кнопка DubTV+ в правом нижнем углу. Её можно перетащить в любое место экрана.

**Плеер**

- Скорость и качество сохраняются при смене серии. Если нужного качества нет, выбирается ближайшее ниже.
- Кнопки «предыдущая / следующая серия» и список серий прямо в плеере.
- Автозапуск при открытии тайтла и смене серии, если браузер разрешает воспроизведение со звуком.
- Кинотеатр: видео на всё окно, а описание и комментарии доступны ниже прокруткой.
- Оставшееся время с учётом скорости.
- Переход к нужному времени и отмена случайной перемотки.

**Скачивание**

- Стрелка рядом с качеством скачивает текущую серию в MP4.
- Несколько серий или весь тайтл — в настройках, вкладка «Плеер».

**Страница тайтла**

- Франшиза рядом с описанием. Превью тайтла появляется при наведении, а на телефоне — по нажатию.
- Описание, комментарии и похожие тайтлы можно свернуть.
- Настраиваются высота плеера и размытый фон вокруг него. Ссылки на Shikimori можно открывать через shikimori.rip.

**Каталог**

- На карточках виден статус из ваших списков («Смотрю», «В планах»…). Сменить его можно прямо с карточки.
- Можно скрыть просмотренное, отдельные тайтлы («Не интересно») и целые жанры.
- На телефоне в фильтрах есть поиск по жанрам и короткий список популярных.

Кнопки «Добавить в…» и «Не интересно» можно выключить в настройках, вкладка «Интерфейс».

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `T` / `Esc` | Включить кинотеатр / выйти из него |
| `Shift+←` / `Shift+→` | Предыдущая / следующая серия |
| `X` / `C` | Скорость −0,25× / +0,25× (от 0,25× до 2×) |
| `G` | Перейти к времени: `3 15` или `03:15`. Одно число — на столько секунд вперёд |
| `Z` | Отменить последнюю перемотку |

Клавиши работают и в русской раскладке. Они не срабатывают, пока вы печатаете текст. Пробел, `F`, `M` и стрелки остаются за сайтом. Горячие клавиши можно выключить в настройках.

## Скачивание серий

Скрипт скачивает видео по кускам и собирает из них обычный файл MP4 прямо в браузере, без перекодирования.

- **ПК (Chrome, Edge):** браузер спросит папку, и серии сохранятся в неё одна за другой.
- **Safari и браузеры без выбора папки:** когда серия собрана, нажмите «Скачать файл». Если в очереди несколько серий, после сохранения каждой нажмите «Продолжить».

Пока идёт загрузка, ссылки на сайте открываются в новой вкладке. Сайт перезагружает страницу при переходе к другому тайтлу, и загрузка в текущей вкладке оборвалась бы.

Не закрывайте окно загрузки, пока браузер сохраняет файл: при закрытии временные данные удаляются.

Ограничения:

- Лицензионные тайтлы и зашифрованные видео не скачиваются.
- Если у браузера нет временного хранилища, серия собирается в памяти, а это не больше 256 МБ. Выберите качество пониже.

## Ваши данные

- Настройки, скрытые тайтлы и жанры хранятся только в этом браузере.
- Списки читаются и меняются в вашем аккаунте DubTV, поэтому нужно войти на сайт.
- Скрипт не отправляет данные сторонним сервисам.

Скрипт опирается на вёрстку DubTV. Если после обновления сайта что-то сломалось, [сообщите об ошибке](https://github.com/Laynholt/dubtv-plus/issues/new?template=bug_report.md).

## Разработка

Код лежит в `src/`. Команда `node build.mjs` собирает из него `dubtv-plus.user.js` и `dubtv-plus.meta.js`.

```bash
npm install
npm test
```

`npm test` проверяет, что сборка свежая, и запускает все тесты. Страницы из `tests/*.html` открываются в Chrome или Edge без окна. Чтобы запустить одну страницу, передайте часть её имени: `node tests/browser.mjs download`.

Выпуск новой версии:

1. Поднимите `@version` в `src/player.js`, выполните `node build.mjs` и закоммитьте.
2. Создайте на GitHub релиз с тегом `vX.Y.Z`. GitHub Actions прогонит тесты и приложит к релизу готовый скрипт.
