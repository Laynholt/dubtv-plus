# DubTV+

<img src="assets/icon.svg" width="80" alt="Логотип DubTV+">

Удобный плеер и каталог [DubTV](https://dubtv.pro).

## Установка

[![Установить DubTV+](assets/install.svg)](https://github.com/Laynholt/dubtv-plus/releases/latest/download/dubtv-plus.user.js)

1. Установите [Violentmonkey](https://violentmonkey.github.io/get-it/).
2. Нажмите **«Установить DubTV+»** и подтвердите установку.
3. Обновите страницу DubTV.

## Возможности

- **Скорость и качество** — сохраняются при переключении серий.
- **Предыдущая / следующая серия** — кнопки прямо в плеере.
- **Кинотеатр с прокруткой** — видео на всё окно, описание и серии остаются доступны ниже.
- **Переход ко времени** — ввод через двоеточие или пробел; одно число перематывает вперёд на столько секунд.
- **Отмена перемотки** — вернуться на прежнее место одним нажатием.
- **Оставшееся время** — с учётом скорости воспроизведения.
- **Компактная страница** — сворачивание описания, комментариев и похожих тайтлов, настройка высоты плеера и фона.
- **Чистый каталог** — статусы из ваших списков, скрытие просмотренного и неинтересных тайтлов.
- **Удобные настройки** — вкладки и переносимая кнопка DubTV+ с сохранением положения.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `T` / `Esc` | Включить или выключить кинотеатр / выйти из него |
| `Shift+←` / `Shift+→` | Предыдущая / следующая серия |
| `X` / `C` | Скорость −0,25× / +0,25×, в пределах 0,25–2× |
| `G` | Перейти к времени: `3 15` / `03:15`, `1 02 30` / `1:02:30`; одно число — секунды вперёд |
| `Z` | Отменить последнюю ручную перемотку, пока доступна кнопка |

Работают с русской раскладкой. Не перехватываются в полях ввода и открытых диалогах. Штатные Space, F, M и стрелки остаются у сайта. Горячие клавиши можно отключить в настройках.

## Данные и ограничения

- Настройки и скрытые тайтлы хранятся локально в браузере. Если хранилище недоступно — только до перезагрузки.
- Статусы читаются из `/profile` с текущей сессией DubTV. Скрипт не меняет аккаунт и списки и не отправляет данные сторонним сервисам. Для обновления статусов нажмите «Обновить статусы» в настройках.
- Нужное качество после установки выберите один раз в меню плеера. Если оно недоступно в другой серии, скрипт выберет ближайшее ниже; если ниже нет — минимальное доступное.
- Улучшения плеера работают на страницах тайтлов. Совместный просмотр не изменяется. Автопропуск опенингов и эндингов остаётся у сайта.
- После изменений на DubTV скрипт может потребовать обновления.

## Сборка и проверка

Исходники: `src/player.js` и `src/library.js`. Готовый скрипт: `dubtv-plus.user.js`.

```powershell
node build.mjs
node --check dubtv-plus.user.js
node build.mjs --check
node --test tests/metadata.mjs
python -m http.server 8765 --bind 127.0.0.1
```

Откройте тесты по очереди и дождитесь результата в заголовке вкладки:

- `http://127.0.0.1:8765/tests/player.html` — скорость, качество и серии.
- `http://127.0.0.1:8765/tests/qol.html` — интерфейс, клавиши и перемотка.
- `http://127.0.0.1:8765/tests/library.html` — каталог, скрытие и статусы.

Тесты используют и очищают общие cookie/localStorage на localhost — не запускайте их одновременно. Просмотр интерфейса: `tests/qol.html?demo=1`. Локальные тесты не заменяют проверку на живом сайте.
